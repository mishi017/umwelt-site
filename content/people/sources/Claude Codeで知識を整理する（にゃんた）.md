Claude Code で「自分専用のナレッジベース（Wiki）」を構築する手法を解説した YouTube 動画。**このリポジトリ（パーソナル Wiki）が採用しているのと同じ手法**で、OpenAI 共同設立者 Andrej Karpathy の発信がきっかけで広まったもの。

## 要点

**全体像**：調べたいトピックについて、AI が読み込み・要約・相互リンクして育てる持続的な Wiki を作る。ページは人間でなく AI が作成・更新する。

**4ステップ**：
1. **収集** — 記事・論文・コードを手元に集める（Obsidian **Web Clipper** が便利）。
2. **コンパイル** — 生データを AI が要約し、リンクのグラフ（エンティティ＝ノード）を作る。
3. **質問** — Wiki に問い、Q&A を Wiki に還元（`/query --save` で概念ページ化）。
4. **保守** — `/lint` で矛盾・整合性をチェック（1日1回の定期実行も有効）。

**RAG との違い**：都度チャンクを検索する RAG と異なり、**一度コンパイルして育てる**。〜100記事・約40万トークン規模なら、エージェント検索＋約100万トークンのコンテキストで十分扱え、ベクトルDBやエンベディングは不要。

**構成**：手元の資料（生データ）／この庭のページ（生成物）／`CLAUDE.md`（スキーマ＝スキルとして定義）。Obsidian の この庭 として開き、グラフビューで関係を可視化。

**応用**：興味関心がログとして溜まるので、「ログを参照して自分が興味ありそうなことを調べて」と頼む使い方ができる（→ このリポジトリの `/daily` に相当）。
