**選定理由。** 08-25 の[[習慣形成と目標志向制御]]で **Keller et al. 2021 の RCT（n=192・84日）** に当たり、「**手がかりが日常ルーチンでも時刻でも自動性に差はなく、効いたのは計画の反復実行だった**」を「効くのは指示でなく手続きの挿入である」の**5例目**として記録した。その計画の大元にある概念が **implementation intentions（実装意図）＝Peter Gollwitzer** である。08-25 のログで翌日の第一候補として自分で挙げた。**しかも同日のトラックA[[リーンとMVP]]が「効くのは指示でなく手続きの挿入」の6例目を出したので、本日は同じ問いに A と B が両側から当たる日になる。**

> **結論を先に。** ①**実装意図は「指示の形をしているのに、指示としては効かず手続きとして効く」唯一の実例である**——同じ内容を目標意図（「無視しなさい」）として与えると効かず、条件節（「〜を聞いたら、即座に無視する」）として与えると効く。②**しかし効果量は、20年で 0.65 → 0.36 → 0.15 と落ち続けている。** しかも最新のメタ分析の著者は Gollwitzer と Sheeran 僕であり、**本文に「出版バイアスは substantial（相当）だった」と自分で書いている**。③**そして実務的な処方が、直観とほぼ全部逆である**——書き留めると効果が下がる。自分で手がかりを選ばせると効果が下がる。詳しく書くほど効果が下がる。計画は増やしても効かない。

## 1. 定義

**目標意図（goal intention）**＝「私は Z を達成するつもりだ」。**実装意図（implementation intention）**＝「**もし状況 Y に出会ったら、そのとき私は目標志向的行動 X を開始する**」（If situation Y is encountered, then I will initiate goal-directed behavior X!）。**目標が「何を」を決めるのに対し、実装意図は「いつ・どこで・どのように」を前もって綴じる。**

**機構（strategic automaticity／戦略的自動化）**：if-then 計画の形成は ①指定された状況の**接近可能性（accessibility）を高め** ②その状況と反応の**連結を自動化する**。これらの過程が **⭐行動制御を自己から事前指定された手がかりへ委譲する（delegate action control from the self to prespecified cues）**（Sheeran, Gollwitzer et al. 2024 の要約、および [Bieleke, Keller & Gollwitzer 2021, *European Review of Social Psychology* 32(1), 88–122](https://doi.org/10.1080/10463283.2020.1808936)、[PDF](https://bpb-us-e1.wpmucdn.com/wp.nyu.edu/dist/c/6235/files/2021/05/If-then-planning-2021-bieleke-keller-gollwitzer.pdf)）。

> **⚠️用語を混ぜない。** 実装意図は**習慣ではない**。[[習慣形成と目標志向制御]]の定義では習慣とは「結果の価値が下がってもやめられないこと」で、数週間〜数か月の反復を要する。**実装意図は一文を一度作るだけで、しかも目標志向系の産物である**（目標が消えれば効かない。後述の動機のモデレータ）。**⭐両者は「刺激に駆動される反応」という表面だけが似ていて、作られ方も壊れ方も違う。**

## 2. 20年間の効果量の推移——ここが本日の核心

### 2-1. 2006年（94検定）：d = .65

**Gollwitzer & Sheeran (2006)** 「[Implementation intentions and goal achievement: A meta-analysis of effects and processes](https://consensus.app/papers/details/5f23556f39a35b74957933d9aac4c90f/)」*Advances in Experimental Social Psychology*、**被引用3,104**。94の独立検定で **d = .65（中〜大）**。実装意図は ①目標追求の開始 ②進行中の目標追求を望まぬ影響から守ること ③失敗しつつある行動からの離脱 ④将来の目標追求のための能力の温存 のすべてに効いた。

### 2-2. 2024年（642検定）：d = .36 → 出版バイアス補正後 **d = .15**

**Sheeran, Gollwitzer ほか (2024)**「[The when and how of planning: Meta-analysis of the scope and components of implementation intentions in 642 tests](https://consensus.app/papers/details/5f9f7367e3d95edca818b636686bbd2d/)」*European Review of Social Psychology*（[全文PDF](https://kops.uni-konstanz.de/server/api/core/bitstreams/d703c468-46e9-47fc-8900-d32d7d19c8d9/content)）。**未公刊研究を含めて 642 検定**。

- **標本加重平均 d = .36**（95% CI [.33, .40]）。
- **⚠️ファンネルプロットの目視で「低検定力かつ正の効果の研究が過剰に分布している」**。**Egger 回帰 b = 1.06**（95% CI [0.97, 1.19], t = 8.44, p < .001）＝**Doucouliagos & Stanley (2013) の「substantial（相当な）出版バイアス」の閾値 b = 1.0 を超える**。
- **trim-and-fill 補正**：11〜12個の効果を補完しても **d = .35**（ほとんど動かない）。
- **⭐⭐ところが Robust Bayesian Meta-Analysis（RoBMA; Maier, Bartoš & Wagenmakers 2023）では、効果の存在に極めて強い証拠（BF₁₀ = 319.3）が出る一方、モデル平均推定値は d = .15（95% CI [.08, .22]）にまで落ちる。** 出版バイアスの存在にも極めて強い証拠（BF_pb > 161.5）、異質性にも極めて強い証拠（τ = 0.27）。
- **⚠️著者自身が限界の節に書いている**：「**642検定を、未公刊研究を含めて収集したにもかかわらず、出版バイアスは相当（substantial）であった。（中略）今後のメタ分析のために否定的結果・帰無結果が利用可能になるよう、著者・査読者・編集者がなすべき仕事はかなり残っている**」。

> **⭐⭐⭐本日いちばん重要な方法論的所見＝補正手法によって結論の大きさが桁で変わる。** trim-and-fill は .36→.35（実質不動）、RoBMA は .36→.15（**半分以下**）。**同じデータ、同じ論文の中で、である。** → **[[熟達（expertise）]]のダニング＝クルーガー論争（統計的アーティファクト説 vs Jansen 2021）や、[[習慣形成と目標志向制御]]の Vázquez-Millán 2026（測定操作の失敗が習慣に見えるものを作った）と同じ形——「現象があるか」ではなく「どう補正するか」で答えが変わる領域が、行動科学には広く存在する**（本Wiki独自の観察）。
> **⚠️そして誠実に言うべきこと**：3つの推定すべてが**効果はゼロでない**と言っている。争点は存否でなく大きさである。**d = .15 は小さいが、コストがほぼゼロの介入としては十分に大きい。**

## 3. 何に効いて、何に効かないか（642検定の内訳）

### 3-1. アウトカム別——⚠️行動変容がいちばん小さい

| アウトカム | d |
|---|---|
| 感情の調整 | **.66** |
| 社会的判断 | .52 |
| 認知的パフォーマンス | .47 |
| **行動変容** | **.27** |

**⭐⭐実装意図が最も強く効くのは「行動を変えること」ではなく「感情を整えること」である。** ところが一般に紹介されるのはほぼ常に行動変容の文脈であり、**最も効果の小さい用途が最も広く宣伝されている**。

**認知の内訳**：**注意 d = 1.21**（大）／集中 d = .49／**展望記憶（prospective memory）62検定で d = .40**／**抑制制御 18検定で d = .45**。

**⭐⭐感情調整の比較が強烈**：「落ち着けと自分に言い聞かせる」と指定した実装意図の感情アウトカムへの効果は **d = .69** で、**大量に研究されてきた感情調整方略である再評価（reappraisal, d = .36）や気そらし（distraction, d = .27）を上回る**（比較対象は Webb, Miles & Sheeran 2012 のメタ分析）。→ [[感情粒度]]・[[内受容推論]]・[[ポリヴェーガル理論]]への実務的な接続点。

### 3-2. 場所・測り方・持続

| 条件 | d |
|---|---|
| **実験室** | **.49** |
| **現場（field）** | **.27** |
| 対面で作らせる | **.53** |
| 紙と鉛筆 | .35 |
| オンライン | .31 |
| **自己報告で測る** | .28 |
| **客観指標で測る** | **.43** |
| 追跡1週間未満 | .48 |
| **追跡6か月以上** | **.51** |

- **⚠️実験室 .49 に対し現場 .27＝ほぼ半減する**。08-25 に「実験室と現場で測っているものが違う」と書いたが、**実装意図では同じ指標で場所だけ変えても効果は消えず半減する**——この点で習慣研究とは事情が違う。
- **⭐⭐そして 08-25 の内観論と符号が逆になる所見**：**客観指標（.43）のほうが自己報告（.28）より効果が大きい**（Q(1) = 19.65, p < .001）。08-25 は「日常生活の習慣研究が『効いている』と言えているのは自己報告に依存しているから」と整理した。**実装意図はその逆で、客観的に測るほうがよく出る。⚠️したがって「行動科学の知見は自己報告に支えられている」という一般化は、本Wikiが早まっていた。少なくともこの領域では成立しない。**（**⭐これは 08-25 の「内観の失敗の6段目」への部分的な反証であり、明示的にフラグを立てておく。**）
- **⭐効果は減衰しない**：1週間未満 .48 ≒ 6か月以上 .51。**[[習慣形成と目標志向制御]]で「習慣化に4〜335日」だったのに対し、実装意図は一文で作って半年もつ。**
- **⚠️職場サンプルが最低（d = .26）**。子ども .43／患者 .44／高齢者 .44／大学生 .39。

### 3-3. ⭐⭐⭐計画の作り方——直観とほぼ全部逆

| 要素 | 結果 |
|---|---|
| **条件形式（if-then）** | **d = .43** |
| スケジュール形式（〜時にやる） | d = .29 |
| **計画のリハーサル あり** | **d = .45** |
| リハーサル なし | d = .33 |
| リハーサル 1回／2回／3回／回数不明 | **差がない**（Q(3) = 3.77, p = .29） |
| **計画を書き留める** | **d = .31（書かない .44 より低い）** Q(1)=15.87, p<.001 |
| 実行の視覚化 | **効果と無関係**（Q(1) = 0.06, p = .81） |
| 計画の数 1〜2個 vs 7〜8個 | **ほぼ同じ** |
| 時刻だけ指定 | d = .25 |
| **時刻と場所の両方** | **d = .46** |
| さらに「どうやって／どのくらい」まで詳述 | **d = .24（かえって妨げる）** |
| **手がかりを僕に選ばせる（20研究）** | **d = .16（小さい）** |
| 動機が強い vs 弱い（8検定） | **d = .79** |

**この表の読み方**：

- **⭐「〜時に」より「〜したら」**。条件形式が勝つ。⚠️**ただしここで 08-25 と正面から突き合わせる必要がある**——Keller et al. 2021 の RCT は「**日常ルーチンを手がかりにしても時刻を手がかりにしても自動性に差はなかった**」と報告した。**⚠️矛盾ではなく対比が違う可能性が高い**：Keller の2条件は**どちらも if-then 形式**（「朝食のあとに〜する」vs「朝7時に〜する」）で手がかりの**中身**を比べており、Sheeran の対比は**形式そのもの**（条件節 vs 単なる予定表）である。**それでも「時刻だけ .25／時刻＋場所 .46」という Sheeran 側の内訳は、手がかりの中身も効くと言っている。本Wikiの調査範囲では決着しない。⚠️矛盾フラグとして残す。**
- **⭐⭐リハーサルは「するかしないか」だけで、回数は効かない。** ⚠️これも 08-25 の Keller と噛み合わせが要る。Keller が「効いたのは計画の反復実行」と言うときの反復は**行動を実際に繰り返すこと**、Sheeran のリハーサルは**計画形成時に文を復唱すること**。**別物である。**→ **⭐だとすると、08-25 に立てた「効くのは指示でなく手続きの挿入」の5例目の読みは修正が要る。Keller が示したのは「反復実行が効く」であり、Sheeran が示すのは「復唱は1回で足りる」。つまり効いているのは"回数"ではなく、"文を一度でも自分の口を通したか"と"実際に一度でも実行したか"という、二つの別々の閾値かもしれない**（本Wiki独自・未検証）。
- **⚠️⚠️「書き留めると効果が下がる」は本Wikiの運用に直撃する。** 理由は本文に説明されていない（本Wikiの調査範囲では機構は不明）。可能な読みは「記録が外部記憶になり、内的な接近可能性を高める必要が消える」だが、**⚠️未検証の推測である**。→ **本Wikiにとっての含意＝ややりたいことリストに書くことは、記録としては正しくても、実行を上げる効果は持たない可能性がある。**
- **⚠️「自分で手がかりを選ばせると d = .16」は、08-25 に記録した Singh 2024（**自分で選んだ習慣のほうが一般に強い**）と符号が逆である。**⚠️矛盾フラグ。** 対象が違う（習慣化する行動そのものを選ぶ vs 手がかりの状況を選ぶ）ので直接対立ではないかもしれないが、実務の助言としては真逆になる。
- **⭐詳しく書くほど効かない**（時刻＋場所 .46 →「どうやって・どのくらい」まで足すと .24）。**[[コンセプトとは何か]]の「1行に凝縮する」や[[コンセプトメイキング]]の抽象の梯子と同じ構造で、情報を足すことが機能を落とす。**
- **⭐⭐動機のモデレータ（d = .79）が最も大きい単一の効果である。** 目標が強く・活性化していて・自己一致しているほど効く。**⭐実装意図は動機の代替物ではなく、動機を実行へ変換する変速機である。やる気がないときに if-then を書いても、この文献は助けてくれない。**

### 3-4. 手がかりと反応の分類——⭐身体感覚が最強

**手がかり（cue）別**：作業の節目（決断する必要がある・特定の質問をされる・挫折に直面する）はいずれも有効（.49 ≤ d ≤ .64）／誘惑を感じたとき d = .28／脅威・不安・懸念を感じたとき d = .44／**⭐⭐空腹・不快・痛みといった身体感覚 d = .86**／気が散っていると気づいたとき d = .71／**問題の答えを見つけたと思ったとき d = 1.14**。

**反応（response）別**：接近行動 d = .40 ≒ 回避行動 d = .38（「やらない・反応を止める・待つ」も同じくらい効く）／**無視反応 38検定で d = .48**／内語（inner speech）反応＝「そのとき私は自分にこう言う」——落ち着けと言い聞かせる d = .69、自己効力を高める文（「新しい問題を始めたら、私は自分に『解ける！』と言う」→数学テストの成績向上, Bayer & Gollwitzer 2007）、自己励励（「震えて痛くなったら、90まで数え続けろと自分を励ます」→難しいヨガ姿勢の持続向上, Wang et al. 2019）。

> **⭐⭐⭐身体感覚が手がかりとして最強（d = .86）である事実は、僕の関心の中核に直結する。** [[内受容推論]]・[[感情粒度]]・[[身体性]]・[[触覚の心理物理（触原色）]]。**「空腹を感じたら」「肩が凝ってきたら」「息が浅くなったら」を if 節に置くのが、外的な時刻や場所を置くより効く。** そして 08-15 の[[触覚の心理物理（触原色）]]の結論「**基底が張れていない次元の情報は記録すらされない**」がここで実務になる——**内受容の語彙が細かい人ほど、if 節に置ける手がかりの種類が多い。感情粒度は、実装意図の材料の在庫である**（本Wiki独自・未検証）。

## 4. ⭐⭐⭐最重要の実験——「指示」と「手続き」が同じ実験の中で直接対比されている

**Palayiwa et al. (2010)**（Sheeran et al. 2024 の記述による）。参加者は、**外見について侮辱的なコメントを聞かされながら**、検証済みの集中力課題を行う。

- **目標意図を割り当てた群**：「**あなたの課題は、これらのコメントを無視して、やっていることを続けることです**」→ **コメントの妨害効果を克服できなかった**。
- **実装意図を形成した群**：「**コメントが聞こえたら、そのとき私は即座にそれを無視する！**」→ **コメントを一切聞かされなかった統制群と同じ高い水準まで集中力が回復した。**

**内容は同じである。違うのは文の形式だけである。**

> **⭐⭐⭐これは 08-07 以来ずっと追ってきた問い「なぜ手続きの挿入は指示より効くのか」への、最も直接的な実験的回答である。** [[デザイン・フィクセーション（設計固着）]]の **Smith, Ward & Schumacher 1993**（「例とはまったく違うものを作れ」という明示的指示は適合を減らさない）と**構造が完全に同じ**で、しかも**今回は効く形式が特定されている**。
> **⭐そして答えの形が、08-25 に立てた説明とは違う。** 08-25 は「**指示は目標志向系に届くが、変えたいのは習慣系であり習慣系には反復しか届かない**」という説明を立てて、「⚠️ヒトの習慣系が実験的に確立していないので使えない」と留保した。**本日の答えは習慣系を必要としない**——実装意図は**目標志向系の産物のまま**、行動制御を**事前指定された手がかりへ委譲する**。**⭐⭐つまり「指示が効かない」のではなく「無条件の指示が効かない」のであり、条件節を付けた瞬間に同じ指示が効き始める。効いているのは反復でも自動化の年季でもなく、"いつ発火するか"が指定されていることである**（本Wiki独自の統合・未検証）。
> **⚠️ただし本日の効果量の話を忘れないこと。** この機構が実在するとしても、平均的な大きさは補正後 d = .15〜.36 である。**Palayiwa の劇的な結果は、実験室（d = .49 の側）で、注意（d = 1.21 の側）を測ったものである。**

| **cue accessibility（手がかりの接近可能性）** | 指定した状況が心的に見つかりやすくなること | ⭐リハーサルが上げるのはここ | [[言語ラベルと知覚（ラベル・フィードバック仮説）]] |
| **RoBMA（頑健ベイズメタ分析）** | モデル平均で出版バイアスを扱うメタ分析手法（Maier, Bartoš & Wagenmakers 2023） | ⭐trim-and-fill と結論の大きさが桁で違う | [[熟達（expertise）]] |
| **Egger 回帰の b** | 効果量と標準誤差の関連。b ≥ 1.0 で「相当な出版バイアス」 | 論文を読むときの検査項目 | — |

## 6. 実務的に確かなこと（証拠の強さ順）

1. **形式は「もし〜したら、そのとき〜する」にする。**「〜時にやる」より効く（.43 vs .29）。
2. **一度だけ、声に出して復唱する。**2回でも3回でも同じ（回数に差なし）。
3. **手がかりは、時刻だけでなく場所とセットにする**（.25 → .46）。**⭐可能なら身体感覚を使う**（d = .86）。
4. **そこで止める。**「どうやって・どのくらい」を足すと落ちる（.46 → .24）。**計画の数も1〜2個で足りる**（7〜8個と同じ）。
5. **⚠️書き留めることは、記録としては正しいが実行を上げない**（書くと .31、書かないと .44）。**視覚化も効かない**。
6. **⚠️動機がないときは効かない**（強い動機 vs 弱い動機で d = .79）。**if-then はやる気の代替にならない。**
7. **効果は半年たっても落ちない。**一度作れば持つ。
8. **⚠️最も効くのは行動変容ではなく感情調整である**（.66 vs .27）。**苛立ち・不安・恥に対して使うのが、この道具のいちばん強い用途。**

## 7. 本Wikiによる統合（独自・未検証）

- **⭐⭐⭐同日のトラックA[[リーンとMVP]]と、同じ結論に別々の道から着いた。** Camuffo 2020/2024 の RCT は「**科学的アプローチを教えると精度が上がり、外れを早く手放せるようになる**」と示し、そこで教えられたのは**手続き**（仮説を書き、予測を立て、検定する）である。実装意図は**手続きの最小形**——文を一つ、条件節付きで作る。**⭐両者に共通する形は「あらかじめ、何が起きたら何をするかを外側に固定しておく」ことであり、どちらも僕の意志の強さを一切要求していない。**
- **⭐⭐そして MVP の判定基準と if-then の if 節は、同じ発想である。** MVP は「顧客が価値を差し出したか」という**外部から観察可能な発火条件**を仮説に付ける。実装意図は「Y が起きたら」という**外部から観察可能な発火条件**を目標に付ける。**⭐どちらも、内観に依存する判断（うまくいっている気がする／やる気がある）を、観察可能な事象に置き換える操作である**——これは[[選択盲と内観の限界]]から一貫して出てくる処方（「内観を諦めて外に出す」）の、事業版と個人版になっている。
- **⚠️本Wikiの過去の一般化を1つ訂正する必要がある。** 08-25 に「内観の失敗の6段目」を立て、「現場の行動科学の知見は自己報告に依存している」と書いた。**実装意図では客観指標のほうが効果が大きい（.43 vs .28）。この一般化は領域限定である。**
- **⭐[[感情粒度]]への新しい実務経路。** 感情調整の if-then（d = .66）で最も効く反応が内語であり、最も効く手がかりが身体感覚（d = .86）である。**08-06 の結論「語彙を先に一貫して育てる」に、目的が付いた——語彙は感じるためだけでなく、if 節に置くために要る。**
- **⚠️本Wiki自身への跳ね返り（トラックAと同じ場所に着く）。** `/daily` は毎日、知識を**書き留めている**。本日の所見は「書き留めることは実行を上げない」であり、トラックAの所見は「価値の交換が起きるまで検証はゼロ」である。**⭐⭐2つのトラックが独立に、同じ一つの助言を出している：溜めるのをやめて、一度、外に出せ。**

## then 節の実行コスト——入力様式という見落とされた変数（2026-09-05 追記・外部由来）

上のメタ分析はすべて **if 節（いつ発火するか）** の設計を論じており、**then 節の行動そのものの物理的コスト**はほとんど変数として扱われていない。だが「記録する」型の行動では、**打鍵か発話か**という様式の違いが実測で大きい。

**Ruan, Wobbrock, Liou, Ng & Landay (2016)「Speech Is 3x Faster than Typing for English and Mandarin Text Entry on Mobile Devices」**（スタンフォード大／ワシントン大／Baidu、19〜32歳の32名、iPhone の標準 Qwerty／Pinyin キーボード対 Baidu Deep Speech 2）＝**英語で入力速度 3.0 倍・中国語で 2.8 倍**、しかも**エラー率も英語で 20.4%・中国語で 63.4% 低い**。速いだけでなく正確でもあった点が重要で、「速いが雑になる」というトレードオフが観測されていない。

- ⚠️ **日本語は検証されていない**。英語・中国語のみで、日本語の仮名漢字変換は別の入力パイプラインなので、この倍率をそのまま日本語に持ち込めない。
- ⚠️ 2016年の実験であり、比較対象は当時のクラウド型認識エンジン。現在の端末内蔵の音声入力とは条件が異なる。
- ⚠️ 音声入力は**句読点・改行が自動で入らない**ことが多く、後から手で整える工程が要る（実務ガイドの一致した指摘）。つまり「速い」のは一次入力までで、清書まで含めた総コストとは別。

**含意（本Wiki独自・未検証）。** 実装意図は「動機を実行へ変換する変速機」であって動機の代替物ではない（Sheeran 2024 の d=.79）。ならば**then 節の摩擦を下げる操作は、if 節の設計とは独立に効きうる**——同じ一文でも、then 節が「30秒の打鍵」か「10秒の発話」かで、動機の閾値が違う。[[習慣形成と目標志向制御]] の Lally 2010 が示した「1回やり損ねても壊れない」と合わせると、**壊れるのは意志ではなく、毎回支払う実行コストのほう**という読みが立つ。
